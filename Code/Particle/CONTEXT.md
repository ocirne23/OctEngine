# Particle
Library documentation for `Code/Particle`. Read `.claude/CLAUDE.md` first (rules, building, style, dependency direction).

* GPU particles + projected decals. Renderer side (ParticlePipeline/DecalPipeline, GPU structs + MAX_* in Layout.ixx) lives in RendererVK; this library is the gameplay layer: `Globals::particleSystem` — `initialize()` before world spawns, `update(renderer, dt)` AFTER `world.update` (rates/bursts → GPU spawn requests; re-uploads every emitter config so live .pfx edits retroactively apply; ages + submits decals)
* Particles simulate ON THE GPU (`particle_begin/emit/sim.cs.glsl`): one persistent pool (MAX_PARTICLES 256K), dead-index stack, two alive lists ping-ponged by frame parity; all dispatches indirect and the OUT alive count IS the draw's instanceCount — spawning never re-records. Sim: gravity/drag/noise turbulence + optional screen-space collision vs last frame's G-buffer; billboards draw in scene color (velocity stretch, flipbooks, per-particle GI+sun lighting, soft depth fade, premultiplied blend with per-emitter additivity 0=smoke..1=fire) in ONE pipeline. Tweaks under Particles/*
* `ParticleEffectDesc` = named set of emitter descs, loaded from `.pfx` text (grammar documented in Effect.ixx; demo Assets/Effects/fire.pfx), cached by path; `createEffect(pathOrDesc, pos, rot)` → RAII `ParticleEffect` (setTransform/setVelocity/setEmitting/burst; destroy retires live particles via KILL flag). Renderer slot API (`createParticleEmitter`/..., MAX_PARTICLE_EMITTERS 256) is main-thread. Textures via `Renderer::loadEffectTexture` into the bindless array
* Decals: `spawnDecal(DecalDesc, pos, normal)` — aging pool (lifetime 0 = persistent, `removeDecal` fades out; oldest non-persistent evicted at MAX_DECALS 4096); pushed per frame via lock-free `Renderer::addDecal`. One instanced draw of unit cubes after the opaque pass (front-cull, no depth test): FS reconstructs the surface from G-buffer depth, projects into decal space (+Z axis), angle-fades, blends premultiplied; DECAL_FLAG_LIT approximates sun + GI. Wraps static AND skinned geometry (pure screen-space)
* `ParticleComponent` (`Component Particle`: `Effect <path.pfx>` + optional `Emitting false`; demo Entities/Debug/particleFire.pre) follows the entity transform and feeds finite-difference velocity
