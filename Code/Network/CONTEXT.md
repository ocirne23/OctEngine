# Network
Library documentation for `Code/Network`. Read `.claude/CLAUDE.md` first (rules, building, style, dependency direction). The game-level replication layer (NetworkManager/NetworkComponent) is documented in `Code/Entity/CONTEXT.md` under Multiplayer; the fuzzer in `Code/NetFuzz/CONTEXT.md`.

* Winsock UDP/TCP + reliable-UDP game protocol (Core-only; Ws2_32 + Bcrypt PRIVATE). Partitions `:Address`, `:Serialization`, `:Socket`, `:Crypto` (internal), `:Reliable`, re-exported from `Public/Network.ixx`. IPv4 only; raw little-endian wire format, no versioning — both ends must match (`protocolId`). `NetHost` is strictly single-threaded, main-thread-only
* `:Serialization`: `NetWriter`/`NetReader` over caller-provided spans — trivially-copyable `write<T>`/`read<T>`, varint (LEB128 + zigzag), strings, unorm/snorm/`writeQuantized`; overflow-safe (`overflowed()`), reads are zero-copy views
* `:Socket`: non-blocking RAII — `UdpSocket` (big SO_RCVBUF, SIO_UDP_CONNRESET disabled), `TcpSocket`/`TcpListener`, `TcpMessageStream` (length-framed), `netResolveHost`, `netGetLocalAddress` (the LAN IPv4 other machines dial — connected-UDP route-selection trick, no packet sent), `netGetExternalAddress` (the PUBLIC IPv4: plain-HTTP GET to checkip.amazonaws.com/api.ipify.org/icanhazip.com — no TLS in the engine, so HTTPS-only services are out; BLOCKING up to a timeout, background-thread only; both feed the main menu's host display). Winsock initialized lazily
* `:Reliable`: `NetHost` — symmetric client/server/p2p over one UdpSocket (simultaneous handshake tie-broken on connect salts). Poll model: `send(peer, bytes, ENetDelivery, channel)`, per-frame `update(dt)` (batches into ≤maxPacketSize packets), drain `takeEvents()`. Deliveries: Unreliable, UnreliableSequenced, Reliable (ordered, ack bitfield piggybacked on every packet, RTT retransmit, transparent fragmentation) on 8 channels (channel rides the kind byte, zero wire cost — bulk transfers don't head-of-line-block). 4-way anti-spoof challenge handshake (responder stateless until the challenge round-trips); `NetHostConfig::encrypt` adds ephemeral ECDH P-256 + AES-128-GCM per payload packet (+16B; Windows CNG, hardware AES) — secure against spoofing/eavesdropping/tampering, not active MITM. Keepalives/timeouts, per-peer RTT/loss stats, live link sim (`simPacketLoss`/`simLatencyMs`/`simJitterMs`)
* ABUSE LIMITS (`NetHostConfig`, enforced before any parsing/allocation): per-source-address token bucket in a FIXED 512-slot hash table (a per-address map would itself be the memory attack; a foreign slot is only stolen once its owner has refilled — else a flooder evicts active peers; an UNUSED bucket must be claimable on the first packet); `maxPacketsPerUpdate` bounds one update globally; `maxPeersPerIp`; `maxQueuedReliablePerChannel` disconnects never-acking peers (`ENetDisconnectReason::Overflow`, latched and acted on in update() — never free a peer inside send()). It is a limit for peers that STOP ACKING, not a buffer for bulk data: a caller streaming many reliable messages (the Entity layer's spawn replay) must pace itself with `getQueuedReliable(peer, channel)` and stay well under it. `NetHostStats::packetsDroppedPerSec` surfaces rate limiting (server title bar)
